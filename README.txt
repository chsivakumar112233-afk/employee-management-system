EMPLOYEE MANAGEMENT SYSTEM
==========================

WHAT IS INCLUDED
- index.html: the web page structure
- style.css: the design and responsive layout
- script.js: employee management features
- README.txt: these instructions

HOW TO RUN (WINDOWS)
1. Download and extract employee_management_system.zip.
2. Open the extracted employee_management_system folder.
3. Double-click index.html.
4. The system opens in your web browser. No installation is required.

FEATURES
- Dashboard with employee totals, active employees, departments, and new joiners this month.
- Add, edit, and delete employees.
- Search employees by name, email, employee ID, department, or job title.
- Filter by department and status.
- Employee details include name, email, phone, department, job title, joining date, status, and monthly salary.
- Saves changes in the current browser using localStorage.
- Includes sample employees so you can see how it works.

IMPORTANT
This is a beginner-friendly front-end demo. Employee data is stored only in the browser on this computer/profile. It is not a secure multi-user production system, has no login/backend/database, and should not be used for confidential employee information. Clearing browser site data may remove saved records. Internet is only needed to load the optional Google font; the app itself works without it.
